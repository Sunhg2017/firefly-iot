# 控制台交互使用说明（2026-11 整改）

> 适用角色: 系统运维管理员、租户管理员、租户业务用户
> 日期: 2026-11-15
> 关联设计: [前端交互友好性整改设计说明](../design/frontend-ux-remediation.md)

## 1. 登录与会话

- 登录失败时错误直接显示在表单上方，不再只弹一条几秒后消失的提示。
- 登录状态过期后会自动回到登录页并提示“登录状态已过期”；重新登录后会回到过期前所在的页面。
- 账号信息或权限加载失败时，页面顶部会出现“账号信息未完整加载”横幅，可点击“重试”，不会直接被登出。
- 忘记密码请在登录页查看提示，联系平台管理员重置。手机号登录需要平台侧下发验证码，控制台当前不提供“获取验证码”按钮。

## 2. 页签与未保存修改

- 顶部页签会在刷新浏览器后保留（同一浏览器标签页内）。
- 关闭页签：鼠标移到页签右侧的 ×；如果该页面有未保存的修改，会先弹出“放弃未保存的修改？”确认。
- 页签较多时可点击右侧下拉按钮，选择“关闭其他页签 / 关闭全部页签”。
- 页签超过一行时左右滚动，不再换行挤压内容区。
- 页面切回时会自动刷新列表数据；表单中尚未提交的内容仍会保留。
- 抽屉/弹窗关闭时，如果表单已修改，会提示“放弃未保存的修改？”。

## 3. 列表与筛选

- 列表加载失败会显示具体原因和“重试”，不再出现空白或“暂无数据”。
- “暂无数据”和“没有符合筛选条件的数据”会区分显示；后者可一键清空筛选。
- 筛选条件变化会自动回到第 1 页。
- 长文本（编码、密钥、报文、Trace ID、播放地址、错误信息等）都有复制按钮，鼠标悬停可看全。
- 统计卡会明确标注“全局”或“当前页”，避免翻页后数字跳变造成误解。

## 4. 选择器替代手工输入

以下位置不再要求记忆或手输数据库 ID：

- 项目成员：搜索用户姓名/账号后选择。
- 项目设备：搜索设备名称后选择。
- 设备所属产品、批量导入产品、产品筛选：远程搜索产品名称或 productKey。
- 租户用量、跨租户共享的消费方：远程搜索租户名称/编码。
- 告警规则指标：从产品物模型属性中选择；物模型为空时会提示先去维护物模型。
- 设备标识类型、SNMP OID、Modbus 寄存器、共享策略范围等改为下拉/结构化录入。

## 5. 危险操作与确认

以下操作现在都有后果说明和二次确认：

- 删除设备/产品/项目成员/设备标签/分组/围栏/角色/用户/租户/规则/订阅/模板/固件/任务记录。
- 停用/启用用户、设备、AppKey、Webhook、通知渠道、规则。
- 关闭告警（关闭后不可再处理）、注销租户（需再次输入租户编码）、暂停租户（需填写原因）。
- TCP/UDP/WebSocket 广播（显示会话数量与消息摘要）。
- 协议解析规则停用/启用、运行时重载插件。
- 一次性密码/Secret Key 弹窗不能按 Esc 或点遮罩关闭，只能“复制后确认关闭”。

## 6. 异步任务中心

- 右上角“异步任务”角标会在关闭面板后继续更新进行中的任务数。
- 面板内可暂停轮询、手动刷新、取消任务、删除记录；删除只删记录，不删除已生成文件。
- 导出/导入任务完成后可下载结果；导入失败可下载错误清单。

## 7. 告警值班

- 告警记录新增“告警内容”列与“详情”抽屉，展示触发值、规则、设备、产品、确认/处理人、处理备注。
- 支持勾选多条后批量确认/批量关闭，完成后显示成功与失败条数；失败会列出具体告警与原因。
- 列表默认 30 秒自动刷新，可暂停并查看“最后刷新时间”。

## 8. 各模块主要变化

- **设备**：编辑设备改用抽屉；标识类型下拉；按分组筛选导出时需先勾选设备；批量命令按命令类型展示字段，服务名可从物模型服务中选择。
- **产品/物模型**：物模型编辑关闭前提示未保存；高级 JSON 使用带校验和格式化的编辑器；删除被引用产品时按钮会说明原因。
- **项目/分组/标签/围栏**：成员/设备改为搜索选择；围栏多边形改为逐点录入经纬度并校验范围；标签颜色改为颜色选择器。
- **告警/规则**：规则表单分步、可查看条件摘要；提交有 loading；关闭告警需确认。
- **定时任务**：中文文案恢复；提供常用 Cron 预设；执行一次需确认；日志清理说明保留天数。
- **协议解析**：关闭编辑器/覆盖已有内容前会确认；模板选中即应用并显示差异说明；调试会话可从在线会话中选择。
- **远程配置/消息/影子**：JSON 输入即时校验；切换目标会清空旧目标；保存前再次确认下发对象。
- **OTA**：任务进度抽屉自动刷新，可暂停；产品名缺失显示“未知产品”。
- **数据与日志**：时间范围选择器补齐；时间统一展示为 `YYYY-MM-DD HH:mm:ss`；日志内容可复制。
- **系统管理**：多步表单不再丢字段；权限分配可搜索/仅看已选；系统内置角色/字典的禁用按钮会说明原因；系统设置中的私钥默认掩码。
- **任务中心/共享策略/视频**：共享策略改为结构化抽屉（保留高级 JSON）；视频地址可复制；任务进度自动刷新。

## 9. 注意事项与限制

- 手机号登录的验证码需要平台侧发送，控制台不提供发送按钮。
- 设备数据历史查询受后端 `limit` 限制，页面显示“最近 N 条”，不是全量分页。
- 事件订阅暂不提供“测试投递”，通知记录暂不提供“失败重投”，需后端补充接口。
- SNMP v3 选项已禁用：后端当前未实现 USM 认证。
- 共享策略的“事件”权限、限流、有效期后端尚未执行，界面保留配置但不代表已生效。
- 审计日志未记录用户名时，详情显示“未记录用户名”，不影响其他字段查看。
