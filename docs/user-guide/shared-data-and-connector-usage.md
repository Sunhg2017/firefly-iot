# 共享数据与连接器能力使用说明

> 适用角色: 系统运维管理员、租户管理员、租户业务用户
> 日期: 2026-11-15
> 关联设计: [共享数据与连接器能力补齐设计说明](../design/shared-data-and-connector-remediation.md)

## 1. SNMPv3 接入

### 1.1 调试工具

1. 打开“SNMP 接入 → 调试工具”。
2. 填写主机地址、端口。
3. 版本选择 `v3（USM）`。
4. 填写安全名称（设备侧配置的 USM 用户名）。
5. 安全级别可留空，系统按口令推断：
   - 不填认证口令 → `noAuthNoPriv`；
   - 只填认证口令 → `authNoPriv`；
   - 认证与加密口令都填 → `authPriv`。
6. 认证协议支持 MD5、SHA-1、SHA-256、SHA-384、SHA-512（默认 SHA-1）。
7. 加密协议支持 DES、AES-128、AES-192、AES-256（默认 AES-128）。
8. 口令至少 8 位；设备侧与页面必须使用同一协议和口令。
9. 点击“测试连接”，再执行“系统信息”或 OID 读取。

### 1.2 采集任务

- 新建 SNMP 采集任务时，版本选择 v3 后同样填写安全名称与协议/口令。
- 采集周期与其他字段与 v2c 一致。
- 失败时页面会显示后端返回的具体原因（如“认证口令至少 8 位”“安全级别需要加密口令”）。

## 2. 设备三元组导出

- 导出范围与当前列表筛选一致：关键字、产品、分组、状态、在线状态、是否排除视频设备。
- 不再要求“按分组筛选时必须先勾选设备”。
- 勾选设备后导出只包含勾选设备；未勾选时导出当前筛选结果。
- 单次最多导出 1000 台设备。
- 导出文件包含设备密钥，属于敏感文件；任务中心下载后请妥善保管并按需删除任务记录。
- 导出任务在“异步任务”中查看进度和下载结果。

## 3. 共享策略

### 3.1 数据权限

编辑共享策略时，“数据权限”勾选项对应：

- 最新属性：读取设备当前属性快照。
- 历史遥测：读取历史时序数据；可在高级 JSON 中用 `telemetryHistory.maxDays` 限制回溯天数。
- 设备事件：读取设备事件（新增）。

未勾选的权限，消费方调用对应接口会收到“无权限”错误。

### 3.2 有效期

- 在“有效期”选择起止时间；留空表示不限制。
- 策略列表会显示“生效中 / 未生效 / 已过期”和具体区间。
- 未生效或已过期的策略，消费方读取会收到“共享策略尚未生效或已过期”（错误码 14002）。
- 消费方的“共享给我的策略”列表会自动跳过失效策略。

### 3.3 频率限制

- 在“限流”中填写 QPS 与每日调用上限；留空表示不限。
- 策略列表显示当前限流值。
- 超出上限时消费方会收到错误码 14001，信息中包含具体上限。
- 限流按策略维度统计，按秒（QPS）和自然日（每日上限）计算。

### 3.4 共享事件读取（消费方接口）

```http
GET /api/v1/shared/devices/{deviceId}/events?policyId={policyId}&startTime=&endTime=&limit=
```

- 需要 `share:read` 权限。
- 返回事件类型、名称、级别、payload、发生时间。
- payload 会按策略的脱敏规则处理（字段名与遥测属性一致）。
- `limit` 默认 100，最大 1000。
- 每次读取都会写入共享审计，动作为 `QUERY_EVENTS`。

## 4. Modbus 采集状态

采集任务列表新增：

- 运行状态：运行中 / 未运行。
- 最近采集：最近一次成功采集并上报的时间；从未成功时显示“尚未采集成功”。
- 最近错误：最近一次失败原因，连续失败时显示失败次数。
- 操作列“刷新状态”可立即重新查询。

说明：

- 状态是连接器当前运行态，连接器重启后会清空并重新积累。
- 任务移除后状态不再返回。
- 采集失败不会删除已有数据，恢复后下一次采集会清空错误并更新最近采集时间。

## 5. 审计日志用户名

- 通过控制台/网关发起的操作，审计详情会显示用户名。
- 内部调用缺少用户请求头时，会回退到当前登录上下文。
- 历史数据中仍可能存在“未记录用户名”的记录，属于当时未记录，不影响其他字段。

## 6. 注意事项

- SNMPv3 的设备侧配置（用户、认证协议、加密协议、口令）必须与控制台一致。
- 共享策略的限流在 Redis 故障时暂时失效，平台会记录告警日志；安全要求高的场景请关注该告警。
- 共享事件只返回事件数据，不返回其他设备属性；读取仍受策略范围与有效期约束。
- 导出文件包含设备密钥，请勿通过非受控渠道传播。
