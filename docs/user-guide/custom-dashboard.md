# 自定义看板 / 运营大屏使用说明

## 1. 适用角色

- 租户管理员、运营人员：定制并保存多套看板，用于日常监控与大屏展示。

## 2. 操作步骤

1. 进入「工作台」页面，切换到「自定义看板」标签页。
2. 点击「新建看板」，填写名称，勾选要展示的组件（概览指标 / 最近告警 / 告警分布 / 设备产品分布 / 在线趋势），保存。
3. 在卡片上：
   - 点击「眼睛」图标：全屏大屏预览（运营大屏）。
   - 点击「编辑」：修改名称与组件。
   - 点击「分享」：开启/关闭租户内分享。
   - 点击「删除」：删除看板。

## 3. 组件数据来源

各组件复用工作台既有统计：设备总数/在线/离线、待处理告警、最近告警、告警级别分布、设备产品分布。在线趋势组件当前为占位，随历史数据补齐后启用。

## 4. 注意事项与限制

1. 组件顺序按创建时勾选顺序排列，暂不支持拖拽。
2. 分享仅限本租户内账号查看，不对外部匿名开放。
3. 需具备 `dashboard:manage` 权限才能新建/编辑/删除/分享看板。
