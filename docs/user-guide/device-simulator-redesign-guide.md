# 设备模拟器使用说明（重设计版）

> 适用角色: 联调工程师、测试工程师、平台运维
> 日期: 2026-11-15
> 关联: [设计说明](../design/device-simulator-redesign.md)、[运维说明](../operations/device-simulator-redesign.md)

## 1. 界面结构

启动并登录后，顶部有四个页面：

- **设备管理**：环境与登录、设备表格、批量创建、批量连接/断开/删除、导入导出。
- **压测中心**：选择设备、配置负载、启动压测、实时看结果、导出报告。
- **运行日志**：查看连接/发送/错误日志。
- **工具**：场景编排、数据模板、压测建议、快捷键。

当前页面会记忆，下次启动恢复。右上角显示当前环境、在线设备数和登录用户。

## 2. 设备管理

### 2.1 新建单台设备

点击“新建”，按抽屉步骤选择协议、产品和接入参数。保存后设备出现在表格中。

### 2.2 批量创建

1. 点击表格上方的“批量创建”。
2. 选择协议、数量、名称前缀、起始序号和位数；右侧会预览首尾名称。
3. 选择平台产品（可选），自动带出 ProductKey；也可以手工填写。
4. HTTP/MQTT 建议选择“动态注册（ProductSecret）”，这样每台设备连接时会自动换取 DeviceSecret。
5. 按需填写接入地址（HTTP/CoAP/MQTT/WS/TCP/UDP/LoRaWAN/SNMP/Modbus）。
6. 勾选“创建后自动连接”并设置连接并发（建议 8-20）。
7. 点击“创建 N 台”。

说明：
- 一机一密产品需要每台设备自己的 DeviceSecret；批量创建只能用统一值或创建后逐台补充。
- 视频/GB28181 不支持批量创建，请在设备详情中单台联调。

### 2.3 表格与批量操作

- 搜索：按设备名、ProductKey、DeviceName 过滤。
- 筛选：协议、状态。
- 勾选设备后可：批量连接、批量断开、批量删除、“用所选设备压测”。
- 勾选跨分页保留；批量操作作用于全部已选设备。
- 单行操作：连接/断开、详情、编辑、复制、删除。
- 删除会先断开连接并清理动态注册，删除后本地配置不可恢复。

### 2.4 设备详情

点击设备名或“详情”，右侧打开设备控制抽屉，可进行协议专属操作（发送属性/事件、读取影子、SNMP/Modbus 读写、视频推流等）。

## 3. 压测中心

### 3.1 选择设备

1. 在“目标设备”中搜索并多选设备；也可点击“选择在线设备”或“选择全部”。
2. 查看已选数量、在线/离线数量和协议标签。
3. 如设备离线，保持“开始前连接离线设备”，系统会先按连接并发连接。

视频/GB28181 不会出现在可选协议中；如果在其他页面带入，会被自动过滤。

### 3.2 配置负载

- **固定请求数**：指定总请求数，所有 Worker 共享计数，达到后停止。
- **持续时长**：指定运行秒数，到达时间后停止。
- **并发 Worker**：同时发送的 Worker 数，建议从 20 开始。
- **发送间隔**：每个 Worker 每轮之间的等待；0 表示尽可能快。
- **爬坡时间**：Worker 逐步启动，避免瞬间打满。
- **超时时间**：单次发送超过该时间计为失败。

### 3.3 配置发送内容

- 上报类型：属性/事件（HTTP/MQTT/CoAP）。
- 数据模板：使用“工具 → 数据模板”中维护的模板。
- 自定义 JSON：填写后覆盖模板；必须是合法 JSON。
- 协议专属参数：
  - MQTT：Topic 模板，支持 `{productKey}`、`{deviceName}`。
  - WebSocket/TCP/UDP：消息模板，支持 `{deviceName}`、`{productKey}`、`{seq}`、`{timestamp}`。
  - LoRaWAN：FPort。
  - SNMP：OID 列表。
  - Modbus：功能码、起始地址、读取数量。

### 3.4 运行与观察

- 点击“开始压测”；运行中可“暂停”“继续”“停止”。
- KPI：已发送、成功、失败、TPS、成功率、进行中、耗时、平均/P50/P95/P99/最大延迟。
- 进度条：固定请求数按完成比例；时长模式按时间比例。
- 图表：TPS 趋势、失败趋势。
- 协议分布：每个协议的发送/成功/失败/成功率/延迟。
- 错误 Top：按错误文案聚合，点击/悬停可看全文。
- 完成后可“导出报告”（JSON），包含配置、设备清单、最终指标和历史。

### 3.5 历史

- 同一会话内保留最近 20 次结果，可对比 TPS、失败数、P95。
- 刷新/退出应用后历史清空；需要留存请导出。
- 切换到其他页面会停止当前压测；长稳压测请保持停留在压测中心。

## 4. 运行日志

- 查看所有设备的连接、发送、错误日志。
- 可只看当前设备日志；支持自动滚动、导出、清空。
- 压测只写开始/暂停/停止/完成等汇总事件，不逐条写每次请求，避免刷屏。

## 5. 工具

- **场景编排**：按“连接 → 等待 → 发送 → 断开”编排步骤，适合演示和回归。
- **数据模板**：维护随机整数/浮点、固定值、时间戳、枚举字段；压测和场景共用。
- **快捷键**：
  - `Ctrl/Cmd + N`：新建单台设备（设备管理页）
  - `Ctrl/Cmd + Shift + C`：批量连接可连接设备
  - `Ctrl/Cmd + Shift + D`：批量断开在线设备

## 6. 限制与注意事项

- 批量创建上限 2000 台，压测 Worker 上限 500；实际能力取决于本机、Connector、Broker 和网络。
- MQTT/WebSocket/TCP 每台设备都是真实连接，1000 台以上请先评估资源。
- SNMP/Modbus 压测的压力在 Connector/目标设备，不是模拟 1000 台独立设备。
- 视频/GB28181 仅支持单设备联调。
- 模拟器保存 DeviceSecret/ProductSecret；导出的设备 JSON 和压测报告请勿公开传播。
- 大批量压测可能触发平台限流、配额和告警，请提前与平台运维确认窗口。
